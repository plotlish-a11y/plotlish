Plotlish Studio · 本地创作者工作台

首次打开会显示一个中性空白草稿，不再内置《Everyone Has a Mission》的小说正文。

操作：运行 启动_英语工作台.bat → 课程与章节管理 → 导入课程 JSON → 选择 ..\lessons\everyone-has-a-mission-01.json

新增章节请修改“章节唯一 ID”；必要时点击「根据标题和章号生成」。保存编辑后导出课程 JSON，再通过工程根目录的“启动_课程发布器.bat”更新本地学生网站。

课程 JSON 不含实际音频。录音素材和视频制作相关状态使用“项目 ZIP”备份。

Windows WASAPI 内录及完整视频导出保留 V2.6 Alpha 代码，但本阶段未在你的 Windows 电脑上完成实机验收。

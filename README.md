直接在悬浮卡片显示免费在线查询所得的中文释义，剑桥和必应仅作为备用外部链接，不会爬取其内容或使用收费 API。移动端须开启「查词」模式后点击单词；关闭后点击句子恢复朗读/选句。第三方免费服务可限制次数、发生 CORS 问题或宕机，届时会显示失败原因入口，不会伪造词义。


## R2.8.1 · 悬浮在线中文释义修复

- 鼠标悬停或手机点击单词后自动请求免费的 MyMemory 翻译接口，直接在悬浮框显示中文；Wiktionary 派生 FreeDictionaryAPI 用作失败后的补充来源。

- 若接口限流、浏览器阻止跨域或接口故障，显示明确失败提示，保留外部词典按钮。**第三方服务可用性无法由本地构建保证。**

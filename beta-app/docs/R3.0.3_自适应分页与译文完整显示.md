# Plotlish R3.0.3：无滚动分页的译文完整显示修复

## 问题

R3.0.2 中，隐藏的高度测量容器 `#measureOuter` 放在 `#readerView` 外部。真实阅读区的 CSS 规则（特别是 `#readerView .readingSentence .translatedInline` 的背景、内边距、下边距、字号及段落间距）没有应用到测量容器，导致错误估算每页能容纳的中英对照句子。正文的 `overflow:hidden` 会直接裁掉超出页底的译文。

## 修复

- 分页计算时把隐藏测量容器移动到 `#readerView` 内，使实际阅读与测量节点共用相同的有作用域样式。
- 同步页面真实字体、字号、行高、字距、断词规则及文本内容区宽度。
- 当译文超出一整页的可用高度时，将译文按完整 Unicode 字符分拆为分页续段，防止极长译文丢失。
- 保留分页模式正文**不滚动**、底部固定导航、右侧英语讲解与剧情插图入口、三种中文显示选项及全部课程格式。
- 页面及翻译模式切换、窗口尺寸变化仍使用已有 `requestPageReflow()` 自适应重新分页。

## 实际验证

真实第一章课程作为**临时测试数据**加载，不放入最终源码 ZIP；通过 Chromium 对 1568×987、1440×900、1024×768、390×844、320×700 的逐句中英对照进行全部页面计算和抽样页面 DOM 位置检查，以及当前句译文、极长中文译文压力测试。逐句英文与译文字符串重组全部与课程原文一致，未发现底部越界。静态构建及原有单元测试亦通过。

说明：本版本专门修复分页遮挡，**未改变 R3.0.2 的右侧「语言讲解／剧情插图」标签结构**；后者是另一项尚待优化的布局问题。

# Plotlish Beta R2.5 · 课程导读、人物与单元规范

## 兼容性

R2.5 是 R2.4 的增量升级：`book.json` 的 `schema_version` 仍为 `plotlish-book-v1`；章节沿用 `sentences`、`translations`、`ids`、`scenes`；对外 `catalog.json` 的 `schema_version` 仍为 `plotlish-r231-web-v2`。只新增 `catalog.books` 字段。

未提供以下文件和字段时，使用旧行为。没有课程时正常显示空书架。

## 课程导读 `packages/<book-id>/course-guide.json`（可选）

```json
{
  "schema_version": "plotlish-course-guide-v1",
  "tagline": "The Runaway Bride · 故事导读",
  "intro": "Brief spoiler-free English introduction.",
  "intro_zh": "不剧透的中文简介。",
  "learning_goals": ["Understand the story and character motivations."],
  "study_tips": ["Read the English first, then check the Chinese translation."]
}
```

- 导读在 `bookView` 作品详情页的“课程导读”选项卡显示。
- 导读不作为每章必读内容，也不强迫用户答题。
- `learning_goals` / `study_tips` 各最多 12 项，须为短文本。
- 导读草稿会被校验，但只有书籍及至少一章均为 `published` 时，导读才会进入生成站点。

## 人物 `packages/<book-id>/characters.json`（可选）

```json
{
  "schema_version": "plotlish-characters-v1",
  "characters": [
    {
      "id": "jiang-mingyue",
      "name": "Jiang Mingyue",
      "name_zh": "姜明月",
      "role": "Narrator",
      "bio": "人物初次出场时即可公开的短介绍。",
      "intro_chapter": 1,
      "portrait": "characters/jiang-mingyue.webp"
    }
  ]
}
```

- 人物图片必须是 `.webp`，路径固定为 `characters/<人物 id>.webp`；不使用图片就把 `portrait` 设为 `""`。
- `intro_chapter` 是该人物首次正式出场章节序号。构建阶段不发布尚无对应公开章节的人物；网页端对第 2 章及之后登场的人物，根据浏览器学习记录解锁展示。
- **人物介绍必须无剧透**。即使页面尚未展示，其文件也可能被技术手段读取；它是体验性解锁，不是秘密信息安全保护。需要保密的真相不能写入已公开 JSON。
- 一个作品最多 40 名人物。人物图会输出到 `assets/characters/<book_id>/<character_id>.webp`。

## 章内学习单元 `chapters/chNNN/course.json` 中的 `units`（可选）

```json
"units": [
  {"unit_id": "my-book-ch001-part01", "title": "Part 1 · Opening", "description": "开场", "start_id": "my-book-ch001-s001"},
  {"unit_id": "my-book-ch001-part02", "title": "Part 2 · The Choice", "description": "抉择", "start_id": "my-book-ch001-s050"}
]
```

- `start_id` 指向既有 `ids` 中某一句，而不是容易漂移的数字索引。
- 单元从第一句开始，并且严格依照正文先后排列，`unit_id` 不可在同一章重复。
- 单元数量上限 30。每个学习单元**只是阅读位置导航**，不会生成重复正文或第二套阅读器，也不会清除学习记录。
- 当前版本不单独统计每个单元完成情况；“本章完成”仍沿用 R2.4 逻辑。

## 运行与发布

在 `beta-app` 根目录执行：

```powershell
python -m unittest discover -s tests -p test_build.py -v
python tools/build.py
python tools/verify_beta_site.py
python -m http.server 8000 --directory dist
```

打开 `http://localhost:8000/`。

本版第一章为 draft。若希望在 beta 站公开测试，**确认内容后手动**把作品与第一章的 `status` 都设为 `published`；只改一处仍不会公开。正式版发布流程与 Main 站部署没有改变。

## 改动边界

保留 R2.4 既有阅读器、数据导入导出、收藏、阅读进度、场景图大图查看等逻辑；不做后台管理系统重写、账号多设备同步、专业音频生产或 24 章内容生成。

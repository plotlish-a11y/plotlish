# Plotlish R3.0 · UI 精修 / 纯源码

## 版本基础和修改范围
基于 R2.9 源码增量调整；没有替换课程导入/构建接口、在线词典服务、Brian 语音选择、进度与备份存储结构。

- 从阅读器站内导航删除重复的“继续阅读”；当前阅读仍可通过目录、首页书架进入。
- “更多”只保留插图显示开关和键盘快捷键；场景图可在正文原位点击放大。
- 删除永远不显示的右栏场景组件、悬浮整句翻译 DOM 及绑定；侧栏保留随文讲解和收藏/朗读/复制。
- 详情页 CTA 动态匹配 `chapter_number`，不再固定写“第一章”。
- 设置分类新增真正的 tab/tabpanel 语义、焦点次序以及 Home / End / 左右箭头切换。
- 仅对中性背景上的小字号陶土色文字加深，提高可读性；保留小说详情满屏背景、Logo 和用户阅读字号/行距设置。
- 修整标题折行、设置弹窗小屏滚动、焦点可见性和减少动画偏好。
- 历史自动测试里对已废弃侧栏插图的断言改为验证图片只在正文，避免测试要求过时设计。

## 开发 / 发布
`cd beta-app` 然后 `python -m unittest discover -s tests -p test_build.py`、`python tools/build.py --packages-dir ../course-packages`、`python tools/verify_beta_site.py`。本源码包不含任何正文/小说图片/课程 JSON；从 `course-packages/` 导入后才出现书籍。

# R2.7 个人书架横向UI修订

本次修改仅涉及 `core/src/styles.css`、`core/src/reader.js` 与相应测试。

- 桌面端单列紧凑书籍卡片，内容最大宽度约1120像素；竖版封面112×168。
- 手机端竖版封面92×138，内容横向排列；隐藏长简介但保留章节状态与进度。
- 以森林绿和米白承接小说详情页视觉；书架首页的标题区缩减高度。
- 真实进度根据现有 `savedPosition` 计算。若读取不到准确位置，隐藏进度条，不估算假百分比。
- 书架筛选、加入/移出、继续阅读、资料页和既有备份协议不变。
- 测试课程和封面仅放在独立演示包。正式源码及空站构建的课程数量为零。

本地HTTP导航在本轮浏览器环境受到策略限制，页面级测试通过 Chromium 的内存注入方式运行真实站点 DOM、CSS 和 JavaScript；部署和真机兼容仍需后续验收。

# Plotlish R3.0.1｜阅读插图分页修复

## 修复依据
R3.0 的 `renderScene` 在分页阅读模式显示了几乎满版的 4:3 场景图，导致文字被挤到下一页；`paginate` 遇到场景图时会直接分页。旧 CSS 对图片 `height:auto!important`、`max-height:none!important` 的覆盖，使“标准”和“大图”模式视觉上缺乏明确区别。此外，测量器 `#measureText` 位于 `#readerView` 之外，图片高度占位样式与实际图不一致。

## 修改
- 在分页模式按文字排版可用面积限定插图宽度，并保持源图片 4:3 比例、不裁剪。
- `compact`（标准）及 `full`（大图）恢复不同尺寸；点击图片仍然可以打开原尺寸预览。
- 自动分页尽可能将插图和紧随其后的正文放在同页，不再无条件创建独立图片页；极小视口或用户选择大图时仍允许独立图片页，不隐藏正文。
- 保证测量器和正式渲染器使用相同的插图几何尺寸，防止图片覆盖下方分页/朗读控件。
- 再分页时固定当前插图页的锚点，避免翻页和当前句译文高度变化造成场景图跳过。
- 连续阅读模式保留相对大的插图，因为滚动布局没有分页高度限制。

## 不变范围
- 课程 JSON 格式、场景索引、图片地址、阅读进度、点击放大、语音、在线词典、随文翻译、右侧知识点与书架逻辑未改。
- 小说详情页全屏封面和背景未改；Logo 和 Favicon 未改。
- 原 R3.0 用户偏好存储结构及课程导入方式不变。

## 验证
- 80 项 Python 构建与静态回归测试通过，JavaScript 语法检测通过。
- 使用独立隔离的第一章 249 句与真实 4:3 剧情图进行 Chromium 验证：1440×900、1024×768、390×844、320×700 四种视口；标准插图模式的“临时结盟”场景可见、有对应英文正文，图片不遮住工具栏，未发现 JavaScript 运行异常和横向溢出。
- 标准及大图两种样式分别在桌面和窄屏检查；大图模式在短屏上可能仍使用专门的图片页，这是有意的显示策略。
- 用临时课程构建的数据及所有图片位于独立 QA 目录，**没有放入最终交付包**。

## 部署提示
- 此包为完整纯净源码而非文件增量补丁；替换旧站核心源码时，应确保 `core/src/reader.js` 和 `core/src/styles.css` 同时使用 R3.0.1 版本。
- GitHub 仓库里的旧课程不会因为上传纯净源码 ZIP 而自动删除。部署前应核对课程资源管理计划；此修复不要求删除线上已有课程。

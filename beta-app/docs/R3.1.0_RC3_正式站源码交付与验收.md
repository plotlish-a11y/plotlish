# Plotlish 正式站源码交付｜v1.0.0-rc.3

日期：2026-10-25（日本时间）

## 定位和重要安全限制

这是正式站专用发布工程的**第三个候选源码版本**，**不是已宣布上线的稳定 v1.0.0**。

- 目标 Cloudflare Pages 项目：`plotlish`，域名 `plotlish.pages.dev`。
- 目标 GitHub 分支：`main`；测试站继续由 `beta` 发布到 `plotlish-test`。
- 使用独立 GitHub Environment/Secrets：`CLOUDFLARE_API_TOKEN_PROD` 和 `CLOUDFLARE_ACCOUNT_ID_PROD`；原有 Beta 凭据不变。
- 仓库变量 `PLOTLISH_PROD_AUTO_ENABLED=true` 表示允许执行正式发布工作流，**不代表候选版本获准部署**。
- 本次增加独立稳定版门禁：`RELEASE_VERSION` 仍为 `v1.0.0-rc.3`，**即使上述变量为 true，也会在部署前中止**。只有经认可后明确改为无 `rc` 后缀的稳定版号，并同时通过全部门禁，才允许自动发布。
- 必须确认 Cloudflare 正式项目生产分支为 `main`；如果是 Git 集成，先关闭 Cloudflare 原生的 production 自动构建，避免与 GitHub Actions 双重部署；再按工作流的检查逻辑设置 `ALLOW_GIT_INTEGRATED_PROD=true`。

## 本版确实修改了什么

1. **修复低动态效果下的字号竞态**：把 `prefers-reduced-motion` 下的 `0.01ms` 动画/过渡改为完全禁用动画/过渡，防止因极短但持续挂起的 CSS transition 导致长章节分页测量到旧字体。
2. **新增真实长度等级的合成压力测试**：249 句、对应中文、三处模拟插图；在 1440、960、390、320px 下连续改字号、行距、中文显示模式，核对实际 CSS 字号、文字完整性、无页内溢出和阅读锚点。此测试不含任何小说原文或课程资源。
3. **生产发布增加明确稳定版号门禁**：`check_production_release_policy.py`；候选版阻止部署，正式版号才有资格继续后续构建、Cloudflare 权限和课程校验。
4. **保留全部旧部署保护**：正式站非空公开课程、课程 JSON 校验、构建 SHA256 清单、目标账户/项目/分支核验、避免旧提交覆盖新部署和线上版本核对。
5. **不修改核心课程接口、存储格式、词典、朗读、插图布局、书架和 Beta 发布工作流**。

## 本地验收项目

- `python -m unittest discover -s tests -p 'test_*.py' -v`
- `python tests/browser_smoke.py`
- `python tests/browser_long_pagination.py`
- `node --check core/src/reader.js` 等 JS 语法检查
- `python tools/build.py --packages-dir ../course-packages`
- `python tools/verify_beta_site.py`
- `python tools/check_production_release_policy.py`：RC 版本**预期失败**。
- `python tools/verify_production_site.py`：本包无课程，**预期失败**。

## 正式发布之前仍须完成

1. 经用户批准的正式课程进入 `course-packages/`，且 `status=published`；这份纯源码 ZIP 没有任何课程内容。
2. 核对 Cloudflare `plotlish` 的真实配置、分支、API Token 权限、原生 Git 自动部署开关。
3. 跨浏览器（Safari、Firefox）、手机真机与真实完整课程的交互回归，尤其是超长译文、长期朗读与频繁切换。
4. 从测试站和已有正式站导出的学习记录，分别进行在正式站的迁入、恢复与回滚验证；两个 Pages 域名的 localStorage 不会自动同步。
5. 形成内容冻结、源码冻结和备份回滚流程后，由明确批准的稳定版本号（如 `v1.0.0`）触发自动上线。

# R2.7 C 阅读器适配与验收记录

## 架构
- 共用原阅读器、分页/连续设置、逐句翻译/知识点和进度保存。
- `sceneCompanion` 仅在桌面端 `width > 800px` 且讲解栏、场景图片均开启、且当前阅读位置已触发场景时显示。
- 场景 DOM 与下载资源均来自 **后来导入的课程数据**。官方纯净源码没有场景文件。
- 图片设 `aspect-ratio:4/3`、`object-fit:contain`、`height:auto`，保持完整构图而不剪切。
- 讲解栏关闭时，图像改为正文内展示；移动端一直使用正文内展示。
- 移动端分页会先尝试把原比例图和后续第一段文字放在同一页，空间不足时图单独占页，不挤成条状缩略图。
- 图片随阅读句子索引 `start_index` 触发，不会优先取第一张未来场景。
- `requestPageReflow()` 必须先切换目标文本容器显隐再测量高度。

## 重要边界
- 延续旧 `plotlish.student.r21.*` 数据和课程句子 ID；不迁移或重置用户状态。
- `compact/full/hidden` 老的设置值继续兼容，新 UI 重命名但不覆盖老用户偏好。
- 浏览器内存模拟已检验 1536/1024/800/390/320px 及手机的分页/连续切换。
- 仍需要实际本地 HTTP、真机与真实持久存储的集成验收。

## 已知设计取舍
- 紧凑桌面采用约 320px 的右栏；没有场景图时自动隐藏图像区，不创建空占位。
- 特别矮的屏幕，完整图片可能需要上下滚动，优先保留原图比例，不裁切。
- 实际图片内容仍属于独立课程资源包。

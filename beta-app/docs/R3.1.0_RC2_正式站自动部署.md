# R3.1.0-rc.2 | 正式站自动部署与验收说明

## 自动发布策略

`beta` => 原测试工作流，无变更。`main` => GitHub Actions 自动测试、构建、Cloudflare 目标校验、生产部署。只有预先设置一次 `PLOTLISH_PROD_AUTO_ENABLED=true` 才启用自动部署。持续使用独立 Cloudflare 正式站账户凭据与生产项目。

## 保持的阻断条件

1. 非 main、变量未开启：绝不部署。
2. 任一测试或浏览器 smoke 检查不通过：不部署。
3. 构建无公开作品/章节、章节中英文 ID 不对齐、文件缺失：不部署。
4. 上传前 artifact 与 SHA256 清单不匹配，或 GitHub main HEAD 已变化：不部署。
5. Cloudflare 账户、项目、域名、生产分支不匹配：不部署。
6. Git-connected Cloudflare 生产自动构建未关闭：不部署（即使开启 ALLOW_GIT_INTEGRATED_PROD）。

## 实际发布前需要验证

- GitHub secrets/variables 正确；GitHub Environment 未配置需要人工批准的 reviewers。
- 正式站生产分支确实为 main；git 集成与 Wrangler 不会双重部署。
- 已审核课程能够被完整发布，用户数据导出/导入可正确恢复。
- R3.1.0-rc.1 剩余字号快速切换的首轮分页竞态尚待长期真实章节回归。
- Safari、Firefox、iOS/Android 真实设备测试仍未完成。
- 在线词典实际连接和 TTS 在不同浏览器环境测试仍未完成。

完成：工作流自动触发、版本自动编号、全部部署文件 SHA256、production 门禁、旧提交保护、输出版本与线上比对。未完成：生产凭据实测、用户数据迁移、全面阅读器测试和真实上线。

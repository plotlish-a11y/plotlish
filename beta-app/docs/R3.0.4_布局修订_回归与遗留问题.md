# Plotlish R3.0.4｜布局修订、回归与遗留问题

审查基线：R3.0.3 纯净源码。此次修改只涉及网站 UI、显示层控制和测试；不修改课程接口、正文、词典、语音、书架或存储格式。本文对状态作明确区分：**修复实现**、**实际验证**、**部分未通过**、**未测试**。

## 已实现并验证

1. **右侧辅助栏结构**：移除 R3.0.2/3 的“语言讲解/剧情插图”互斥标签页。宽屏恢复插图在上、语言讲解在下，同时可见；英文与句下中文仍留在阅读区。图片可点击放大。顶部讲解独立开关仅影响讲解，不再让右侧插图因关闭讲解而跳入正文。
2. **插图可见性**：桌面端仅显示当前句及之前的最近一幅插图，避免提前预告后文；到达第一幅插图前不占用无意义的大图片卡片。插图是否显示由独立的原有图片设置决定。不更改 `start_index` 内容约定。
3. **断点调整**：双栏只在视口宽度超过 960px 时使用，960px 及以下采用单栏正文与随文紧凑插图，并可由阅读栏按钮打开语言讲解抽屉。为 801–960px 增加实际的抽屉 CSS 及蒙层；避免只修改 JS 断点却没有配套控件。
4. **讲解信息精简**：只有一个知识点时不再重复出现选择标签和大标题；保留多个知识点的切换入口、释义、例句、听本句、复制、收藏及表达朗读。
5. **移动端触控**：小屏下优先提高阅读器关键操作的点击区域（普通阅读、朗读、翻页），但未彻底重新设计顶部工具栏。
6. **源码纯净性**：没有加入小说正文、课程 JSON、封面、人物立绘和剧情插图；保留原有构建工具、部署工作流、测试、历史技术说明和 `pl` 品牌资源。

## 验证记录

- Python 自动测试：**86/86 通过**。
- `node --check core/src/reader.js` 通过。
- 零课程静态构建及 `verify_beta_site.py` 校验通过：**0 部小说 / 0 章 / 0 个课程素材**。
- 以单独的真实第一章临时课程/图片（不打入正式压缩包）在 Chromium 进行视口检查：1440×900、1024×768、961×720、960×720、810×720、390×844、320×600。宽屏图片与讲解同时显示；隐藏讲解图片仍可见；960/810/390/320px 讲解抽屉可打开；未见横向溢出与 JS 运行错误。
- **部分通过：** 字体/行距更改后的分页在已测样本中二次测量后可恢复，但“在切换讲解状态后连续改字号”的某些运行中，首轮分页仍延迟沿用旧字体指标，可能短暂裁切内容。本轮测试未稳定证明此项彻底修复。因此不应将该项标记为已修复。

## 发布注意事项

**这是 R3.0.4 候选源码（Candidate）**，可以用于测试站，但在 P0 字号/行距分页稳定性通过后再考虑作为正式站基线。不要仅凭自动测试通过就宣布全部阅读状态已经验收。此前导入课程的数据不会被源码包自动删除；若把纯净源码覆盖含课程的旧 GitHub 仓库，仍需按需手动移除旧课程目录。

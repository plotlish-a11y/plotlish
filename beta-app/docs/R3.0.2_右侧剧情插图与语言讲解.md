# R3.0.2 · 插图回归右侧（纯界面修改）

- 桌面宽度 >800px：右侧辅助区域增加「语言讲解 / 剧情插图」独立标签，默认语言讲解。只有读到插图起始句后才会显示该图片，不提前剧透。插图跟随当前句更新，可点击放大。
- 800px 及以下宽度：右栏隐藏，插图继续紧凑地嵌入正文，图片测量沿用 R3.0.1 修复。
- 如果桌面端主动收起讲解辅助栏，插图将回退到正文中，避免图像功能无法访问。
- 插图设置 compact/full/hidden 三种模式、分页/连续阅读、在线词典、读音、翻译和本地学习数据保持原逻辑及存储键。
- 右侧标签不修改/保存学习数据，不修改 JSON 课程格式。
- 未导入课程的纯净源码包没有任何小说正文或剧情图；可以后续独立导入。

## 代码与兼容性

- 删除已移除 HTML 按钮 `speakSelected`、`copySentence` 的无效静态事件绑定；讲解区的动态按钮仍保留原有朗读与复制事件。
- 移动端不会另外装载右侧图像的 DOM 实例，降低重复加载。
- 兼容旧的阅读偏好 `scenes` / `imageMode` / `explain`，没有迁移用户存储键。
- 点击知识点时自动切回语言讲解标签，右栏 Tab 可用方向键切换。

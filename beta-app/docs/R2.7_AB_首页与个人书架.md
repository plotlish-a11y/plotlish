# Plotlish R2.7 A+B：纯净核心、首页运营、个人书架

## 交付边界

`core/` 是通用站点，无任何小说图片或课程。`packages/` 在纯净源码中只有说明文件；不要将演示课程解压在正式核心内。`dist/` 是工具生成的网站，可删除后重新构建。发布时从外部课程目录导入，不修改静态站点的功能源码。

## 站长配置首页

`homepage.json` 与作品目录同属于运营层，不是读者存储，也不改变 `book.json` 的发布状态。配置格式：

```json
{
  "schema_version": 1,
  "featured_book_id": "example-book",
  "sections": [
    {"id": "editor-picks", "title": "编辑精选", "book_ids": ["example-book"]}
  ]
}
```

上述示例只是 JSON 格式示意，不包含课程素材。引用的作品必须是已发布且至少开放一章。传入不存在或草稿作品时，构建应失败，不能自动展示第一本书填补推荐区。

构建：

```
python tools/build.py --packages-dir /path/to/real-content --homepage-config /path/to/homepage.json --output dist
python tools/verify_beta_site.py
```

纯净空站：`python tools/build.py --output dist`，主页推荐自动为空。只上传核心源码不会自动启用任何课程。

## 读者个人书架

- `plotlish.reader.library.v1` 用于本地书架；独立于 `plotlish.student.r21.*` 旧学习数据。
- 加入书架与移出书架不会改动已保存的章节阅读位置、生词和复述记录；开始精读会自动入架。
- “想读”：加入但未开始；“在读”：至少一章已开始，但尚未完成全部公开章节；“追更中”：已完成全部已公开章节、作品仍在连载；“已读完”：已完结且全部已公开章节完成。
- 从目录下架的书可保留在个人书架中并显示不可阅读提示；不自动删除本地数据。
- 本地书架不是云端同步：换设备或清理浏览器数据前要导出备份。

## 备份格式

课程阅读器导出 `schema:4`，兼容导入旧 `schema:2/3`。`data.bookshelf` 是个人书目 ID 数组；`data.rawRecords` 保存旧本地学习数据键及原始值，避免临时无课程时导出造成旧章节学习记录丢失。

零课程网站同样可以从“设置→数据与隐私”导出 schema 4。导入时，合并模式保留现有数据，替换模式需要明确确认。不进行浏览器账号同步。

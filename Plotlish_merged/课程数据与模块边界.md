# Plotlish · 课程数据与模块边界

## 1. 三个独立模块

1. **Author (`author/`)**：本机 HTML 工作台，负责编辑小说、翻译、句子知识点、英语讲解卡、录音和视频草案。它导入/导出课程 JSON；其 HTML 不应内置任何一部小说。
2. **Lesson (`lessons/`)**：每章唯一的、可编辑的 `english-reader-lesson-v2` JSON，记录 `lesson_id`、原文、逐句译文、知识点、词卡、语法讲解、练习、作品信息。它是内容层，与页面布局无关。
3. **Reader (`site/`)**：学生使用的只读网页。网页程序中不需要、也不应包含任何创作者工具。学生课程由发布器转换为 `ers-public-v1` 格式，收录在 `site/courses/`。不需要学生手动导入 JSON。

此外 `tools/` 是本地发布管线：检验源文件 → 生成网站 JSON → 更新 catalog；不等同于在互联网上部署。

## 2. 源课程重要字段

```json
{
  "format": "english-reader-lesson-v2",
  "lesson_id": "a-unique-story-chapter-01",
  "article": "An English paragraph. Another sentence.",
  "sentence_ids": ["001-<calculated-hash>", "002-<calculated-hash>"],
  "lesson": {
    "title": "The Story Title",
    "chapter": "01",
    "series": "English Through Stories",
    "subtitle": "中文副标题",
    "level": "A2",
    "genre": "MYSTERY",
    "synopsis": "故事简介",
    "sentence_translations": ["第一句翻译。", "第二句翻译。"],
    "translation_source_hash": "<calculated-article-hash>",
    "grammar": {}, "cards": [], "question": "", "questionHelp": ""
  },
  "annotations": []
}
```

**注意：这里的 hash 字符串为说明占位符，不是可以直接发布的数据。** 应通过创作者工作台导出，以生成正确的指纹和句子 ID。现阶段 V2 仍存储翻译数组，和独立的 `sentence_ids`、正文指纹一起共同验证绑定关系。未来如果要支持复杂的逐句编辑与重排，再考虑将原文/译文合并为每句的稳定对象；目前不必为此重写工作台。

## 3. 基本一致性规则

- `lesson_id` 全工程唯一（同一章修订保持原 ID）。
- 每章正文按相同 `Intl.Segmenter('en')` 规则分句，翻译必须一一对应且不能空缺。
- V2 文件必须包含正确的 `sentence_ids` 和 `translation_source_hash`，保证正文与翻译在结构上相符。
- 每一条 `annotations` 必须包含有效的 `sentenceIndex`，标注短语必须确实出现在指定的英文句子中。对词语匹配允许大小写差异，但会输出真实原文中的拼写。
- 正文字句变动导致指纹变化，不能不经审校直接沿用旧译文。
- 发布前进行人工英语/中文质量与版权审核；程序无法证明翻译语义或英语难度标签正确。
- 学生界面只使用公开版课件；任何录音草稿、账号信息、编写备注、备份文件必须保留在 `site/` 以外。

## 4. 发布与备份

发布器读取选中的作者 JSON，产生公开章节和书架目录。更新已有同 ID 课程时必须明确勾选允许更新，旧版保存在未公开的 `private_publish_history/`。删除学生章节不会删除 `lessons/` 中的可编辑版本。

当前 `site/` 内自带一章演示内容；内容的额外副本仅用于学生端发布输出，不需要修改多份课程文件。制作新章时先导入/编辑一个独立 JSON，发布器会自动写入目录。

## 5. 当前代码限制

- 旧版创作者工作台仍是一份多脚本的较大型 HTML，**内容已分离，但代码内部各个录音/视频子模块尚未拆成独立 JS 文件**。本轮优先保证原有录音与视频接口不被重写；后续可在完成 Windows 实机验收后逐步模块化。
- 用户阅读进度保存在浏览器本地，缺少跨设备同步。
- 使用浏览器语音作为临时朗读解决方案，未接入经过授权的预生成商业音频。
- 当前课程没有自动评分的测验模块，也没有宣称达到 CEFR 等级的有效测评体系。

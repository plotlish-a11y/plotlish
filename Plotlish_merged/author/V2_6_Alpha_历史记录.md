# English Reader Studio V2.6 Alpha — 变更与验收

## 已完成的实现
- 增加 Windows PowerShell 本地启动器和自带 C# WASAPI Loopback 录音引擎源码；无外部付费 TTS 或 Python 依赖。
- 免费 Microsoft Edge 在线语音选择、逐句点击朗读、全文连续朗读、暂停/继续继续保留。
- 增加试录当前句、录制全文、内录停止、试听、下载和测试音轨删除入口。
- 内录检测非静音后才把 WAV 导入旧版 `clipBlobs`，完整音轨由用户确认覆盖；粗略时间戳明确标识为未校准。
- 中文讲解录音默认使用耳机模式（英语参考音不自动暂停麦克风），可改为外放自动暂停。
- 将旧版按页真人朗读、时间校准和音轨导入归入高级设置；隐藏重复语音说明和实验性标签页共享内录入口。
- 保留旧课程 JSON、项目 ZIP、现有中文讲解和浏览器 WebM 视频编排功能。

## 已完成的测试
- 语法检查：新版注入的 JS 通过 `node --check`；HTML 中新增脚本的独立执行无页面异常。
- Chromium `set_content` 注入测试：可以加载、显示工作区、新卡片以及高级工具；浏览器禁止本地 HTTP 导航，未走真实 Windows 服务。
- 模拟本地服务测试：健康检查、录制开始、停止、读取有效 WAV、将音频保存为“数字内录测试音频”，并更新按钮及录音列表。
- 检测失败逻辑：没有有效音频时，不会替换既有英文音轨（Windows 返回此状态后走此分支）。

## 尚未验证的项目（必须在用户 Windows 10/11 上试）
- PowerShell 5.1 `Add-Type` 能否按当前源文件成功编译 CoreAudio COM/WASAPI 互操作类。
- Microsoft Edge Online TTS 能否由默认输出设备的 WASAPI Loopback 捕获，是否剪掉尾音或混入其他声音。
- 连续整章内录后的音频时长、对齐精度、WAV 保存与恢复。
- 完整视频生成及 H.264/AAC MP4 一键渲染。

## 验收门槛
只有当用户能在 Windows 设备上试录当前句，并通过听音确认捕获了真正的在线英语人声之后，才将 WASAPI 路线认定为实际可用。整章长录、项目 ZIP 导入、视频导出需单独验证。
